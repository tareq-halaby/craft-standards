🎯 The Mission: End Erroneous UI Fragmentation

Storytold develops over 20 creative, CAD, video, and productivity desktop applications in Rust. With over 6,000 contributors, independent development teams naturally solve common problems in subtly divergent ways: keymaps clash, dialog dismissals invert button orders, and timeline scrubbers behave unpredictably.

ArtCraft Standards (craft-standards) establishes an authoritative, contract-enforced foundation. Every application adheres to identical ergonomic muscle memory, AccessKit accessibility trees, BiDi spatial mirroring, and sandbox invariants—enforced automatically before any code can merge.

⚖️ Monorepo Transformation: Before vs. After

Capability Legacy Disjointed Monorepo Unified ArtCraft Standards (v0.2.0)
Tool Cycling & Hotkeys Each app re-invented hotkeys; frequent collisions between PhotoCraft and CADCraft. STD-INPUT-001: Universal [V, M, B] tool slot cycling and spring modifiers across all 20 apps.
Accessibility (AccessKit) Manual ad-hoc tagging; screen readers broken in timeline and canvas views. STD-A11Y-001: Mandatory AccessKit node hierarchy and 7:1 AAA contrast enforced via headless CI audits.
BiDi & RTL Mirroring Incomplete text-only translation; toolbars and timelines misaligned in Arabic/Hebrew. STD-I18N-001: Full shell spatial inversion with directional CSS properties and egui layout galley shaping.
File I/O Sandboxing Raw std::fs calls caused path traversal vulnerabilities and broke automated agents. STD-SHELL-003: Sandboxed craft_fs::AutomationRoot restricts I/O to explicitly mounted directories.
Autonomous AI Agents Agents hallucinated non-standard APIs; maintainers spent hours manually correcting PRs. AutoCraft MCP Gateway: Claude Code, Cursor, and AutoCraft query standard rules over stdio before emitting code.

🏛️ The 7 Architectural Pillars

01 · Interaction & Gestures

Slot cycling, spring tools, canvas physics, and 14-stop gradient color proofing.

02 · Navigation & Layout

Universal document tab switching, dock collapsing, arrow-key scrubs, and JKL timecodes.

03 · Accessibility (a11y)

Automated AccessKit tree audits, 7:1 AAA contrast ratios, keyboard rings, and reduced motion.

04 · Internationalization (i18n)

Full shell BiDi mirroring, Arabic/Hebrew typography, and locale-aware numeral formatting.

05 · Shell & Sandboxing

Clipboard interchange, dialog button hierarchies, dirty state recovery, and confined file access.

06 · Unified Shared Libs

Keymap normalization, widget primitives, host font activation, GPU lifecycles, and The Keep Rule.

07 · Governance & Licensing

Clean-room reverse engineering, patent isolation, contributor issue claiming, and machine-verified RFCs.

# Storytold Craft Creative Suite Contributor & Agent Guidelines
- Monorepo Architectural Ground Truth: https://tareq-halaby.github.io/craft-standards/
- Invariant Testing: All new UI features MUST comply with the 28 Craft Standards.
- Crate Boundaries: Respect 'The Keep Rule' (STD-LIB-005). Never write app-specific code in core crates.
- ToolSlot Ergonomics: Multi-tool buttons MUST shield against rapid double-clicks (STD-INPUT-001).
- Filesystem: App code must NEVER access `std::fs` directly; route through `craft-fs` sandboxing (STD-SHELL-003).
- Accessibility: Every widget MUST register AccessKit nodes with explicit role, label, and AAA contrast (STD-A11Y-001).
- BiDi / RTL: Full shell direction mirroring is mandatory. Never hardcode Left/Right padding (STD-I18N-001).

You are an expert Rust graphics & desktop engineer working on the ArtCraft 20+ app monorepo.
Always adhere strictly to the 28 Craft Standards (https://tareq-halaby.github.io/craft-standards/):
1. UI framework is egui with wgpu backend. Use `craft-widgets` design tokens.
