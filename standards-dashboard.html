STD-A11Y-001: AccessKit Node Tagging and Automated CI Accessibility Audit

# STD-A11Y-001: AccessKit Node Tagging and Automated CI Accessibility Audit

## 1. Abstract
Assistive technologies (screen readers, speech input, screen magnifiers) rely on accessibility trees generated by AccessKit. Custom widgets in egui that are allocated via `ui.interact` or `allocate_exact_size` produce empty, unnamed nodes unless explicitly annotated. This standard specifies mandatory accessibility tagging and automated CI testing.

STD-LIB-001: Universal Cross-Platform Printing and Prepress Pipeline

# STD-LIB-001: Universal Cross-Platform Printing and Prepress Pipeline

## 1. Abstract
Printing across desktop operating systems involves disparate backends: Windows GDI / XPS on Windows, CUPS on Linux and FreeBSD, and CoreGraphics/NSPrintOperation on macOS. This standard dictates that all ArtCraft applications must route document output through `craft-libs::craft-print` rather than writing platform-specific print code.
